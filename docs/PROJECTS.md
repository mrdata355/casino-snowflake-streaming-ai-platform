# Portfolio Project Map

This repository contains eight integrated, independently explainable senior-engineering projects.

1. **Snowflake Casino Lakehouse Foundation** — databases, schemas, RBAC, warehouses, resource monitors, security policies, Time Travel, and validation.
2. **Real-Time Gaming Event Platform** — Kafka/Pub/Sub producers, Spark Structured Streaming, watermarks, deduplication, checkpoints, DLQ, and replay-safe Snowflake sinks.
3. **Snowflake Native Incremental Framework** — Snowpipe, Streams, Tasks, Dynamic Tables, CDC, and governed publication.
4. **Casino Revenue and Profitability Products** — slot performance, net gaming revenue, labor alignment, loyalty, attribution, and location profitability.
5. **AI/ML Feature and Scoring Platform** — point-in-time training sets, time-based validation, MLflow registration, model output contracts, and drift monitoring.
6. **Cortex Conversational Analytics** — semantic definitions, synonyms, verified questions, role-aware access, and audited AI consumption.
7. **DataOps and Infrastructure Platform** — Airflow, dbt, Terraform, GitHub Actions, environment promotion, and rollback.
8. **Data Contracts, Governance, and Observability** — JSON schemas, ownership, reconciliation, PII controls, freshness, cost attribution, and incident response.

The modules form one end-to-end platform, but each can be demonstrated as a focused project story in an interview.
