# OpsReady - Vercel MVP

Self-contained Vercel-ready demo of a recurring DataOps proficiency system.

## Included in the deployed MVP
- Engineer readiness dashboard
- Weekly streaming micro-drill
- Monthly end-to-end incident
- SOP acknowledgement
- Built-in simulation library
- FinOps lab
- Incident-to-training generator
- Certification ladder
- Manager readiness dashboard
- Browser-local demo persistence

## Enterprise upgrade path
- SSO
- central database
- manager/team assignment
- auditable attempts
- recurring scheduling/reminders
- sanitized real incident ingestion
- LMS/HRIS integration
- centralized scoring and certification

This MVP intentionally avoids company branding and confidential production claims.
